# Kurage 陳情ナビ（名古屋市）

困りごとを、名古屋市会に出せる**陳情書**の形にする。所管の常任委員会と提出先、
次の定例会までを1画面で返す。

## 設計で守っていること

- **締切日を書かない。** 市会は「各定例会等で付議・送付するための締切日を設けています」
  とするだけで、**具体的な日付を公表していない**。推測すると間に合わない日を示す恐れが
  あるので、開会日だけを示し、締切は事務局（052-972-2095）に確認するよう案内する。
- **市のサイトの本文を転載しない。** 持つのは事実（日付・所管・様式の項目）と出典URLだけ。
- **委員会の判定にLLMを使わない。** 語の一致で選び、当たらなければ「判定できませんでした」
  と出す。当てずっぽうで1つ選ばない。何の語で判定したかを画面に出す。
- **陳情に押印は要らない**（署名又は記名）。請願は署名又は記名押印で、紹介議員も要る。
  ここを取り違えると受理されない。

## 出典（2026-09-19 に一次情報で確認）

- 名古屋市会「請願・陳情の案内」 https://www.city.nagoya.jp/shikai/bouchou/1031732.html
  （様式は同ページの書式例の画像 gazou1〜4.png から読み取った）
- 年間スケジュール https://www.city.nagoya.jp/shikai/about/1030648/1030649.html

## 動かす

    KCHINJO_PORT=18377 .venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 18377
    python -m pytest tests/ -q

`app/templates/index.html` は **Jinja を通さず静的に返す**（JSの `${...}` やCSSの `{` が
Jinja の構文と衝突するため）。

## 他の自治体に広げるとき

`data/<市区町村>.json` を足す。持つのは会期・委員会の所管語・提出先・宛名だけ。
**締切が公表されている自治体なら、そこは書いてよい**（名古屋は非公表）。
